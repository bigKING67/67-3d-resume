小红书、抖音、天猫、京东同时花钱时，平台后台的 ROI 无法直接回答：增长来自广告、旺季、大促、库存，还是本来就会上涨的品类需求？

> **数据声明：**本案例使用按照全域电商经营机制生成的合成 Geo-week 数据，拥有可检验的媒体贡献真值；不代表任何真实品牌预算或销售结果。

## 业务场景

场景覆盖 156 周、12 个区域，共 1,872 行周度面板数据，名义三年预算池 3,600 万元。媒体包括小红书聚光、抖音巨量千川、天猫万相台无界版和京东京准通；结果变量是退款成熟后的净 GMV。

季节、大促、品类需求、库存和竞品压力共同塑造自然销售基盘。媒体部分则分别带有跨周 Adstock 记忆和边际递减，避免把当周花费与当周销售做成一次简单相关回归。

![自然需求、经营条件、媒体投入与净 GMV 的关系](./works/analysis/omnichannel-mmm-value.webp)

*市场需求指数只由媒体发生前可观测的区域规模与经营变量构成；会被广告影响的品牌搜索不放进主控制集，避免把媒体作用当成控制变量扣掉。*

## 模型怎么工作

四个平台先按各自衰减率做 Adstock，再进入凹形饱和变换；缩放后的响应特征与前置市场需求指数一起进入带正系数约束的 Ridge 响应模型。最后 13 周完全留出，区间由 200 次区域 bootstrap 生成。

![Geo-week MMM 从媒体响应到预算方向的建模流程](./works/analysis/omnichannel-mmm-system.webp)

这是一套已经验证过真值恢复能力的 MMM response benchmark。代码预留了 Meridian 1.6.1 数据适配合同，但本次没有 MCMC 采样回执，因此页面不会把 bootstrap 区间写成 Bayesian posterior，也不会声称已经完成贝叶斯 MMM。

## 验证结果

- 留出集 WAPE：**2.25%**；原始花费 OLS 基线为 2.95%。
- 四平台贡献份额 MAE：**1.964 个百分点**。
- 四个平台的已知贡献真值均落入各自的 90% geo-bootstrap 区间。
- 估计 / 真值份额：小红书 11.2% / 14.3%，抖音 43.1% / 40.0%，天猫 28.7% / 29.5%，京东 17.0% / 16.1%。

![四平台贡献份额的合成真值与模型估计](./works/analysis/omnichannel-mmm-evidence.webp)

*模型验证的是“在已知机制下能否找回贡献”，不是给真实业务制造确定答案。小红书虽是误差最大的渠道，仍通过预先设定的总份额误差与区间覆盖门禁。*

## 从贡献到预算

合成真值优化器给出的 sanity check 方向是：当前约 15% / 40% / 28% / 17% 的小红书、抖音、天猫、京东预算，调整为约 12% / 40% / 32% / 16%。这只证明优化器能在已知响应曲线中找到更好的组合，**不是现实投放建议**；真实预算必须再加入平台起投门槛、库存、利润、品牌目标与实验校准。
